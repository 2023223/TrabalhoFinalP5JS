# Projeto Final de Código Creativo

Para este exercício tive como objetivo descobrir como criar um padrão que pudesse aplicar no fundo dos meus desenhos e no vestuário dos meus personagens e mudasse de cor ao clicar no ecrã com o rato.
O padrão foi criado com ajuda do tutorial "Making Simple Patterns in p5.js" de Steve's Makerspace (https://www.youtube.com/watch?v=ig0q6vfpD38&t=158s). Surgiram várias complicações na colocação da imagem, um desenho feito no Krita, sobre o padrão geométrico feito anteriormente. Após vários tutoriais de The Coding Train (3.3: Events (mousePressed, keyPressed)- Processing Tutorial - https://www.youtube.com/watch?v=UvSjtiW-RH8&t=114s ; 
7.8: Objects and Images - p5.js Tutorial - https://www.youtube.com/watch?v=i2C1hrJMwz0&t=249s), mantiveram-se as dificuldades em fazer com que a imagem aparecesse sobre o padrão. depois de várias iterações no código sem sucesso, conversei com o gemini, a IA da goodle, para tentar compreender a razão para a imagem não aparecer. Após seguir as primeiras indicações, o padrão também não aparecia, substituido por uma loading screen.
De acordo com as respostas seguintes, a função preload() estava a bloquear o código, porque já não existe na versão mais recente da biblioteca de p5.js. Assim, substitui esta função por async/await por recomencação da inteligência artificial, o que fez com que a imagem finalmente surgisse sobre o padrão geométrico.
As dificuldades sentidas neste projeto relacionam-se com a minha falta de compreensão do código e dificuldade em compreender as instruções dadas pelos tutoriais e pelo gemini. Concluindo, não estou satisfeito com o resultado final, nem em termos do seu aspeto estético nem relativamente às minhas aprendizagens durante este projeto.
